# Security policy

## Supported versions

Only the newest release gets security fixes.

## Report a problem

Do not open a public issue for a security problem.

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and the steps that cause it.

You get an answer in 7 days or fewer. When a fix is ready, the release notes give you credit, if you want.

Picnest reads, copies, moves, and deletes files in the folders that you select. A bug that changes or deletes files outside those folders is a security problem.
